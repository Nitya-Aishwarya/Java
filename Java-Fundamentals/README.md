# Java Fundamentals – Detailed Notes

Java is one of the most widely used programming languages in the world. It is commonly used for backend development, Android development, enterprise applications, web applications, and large-scale systems.

These notes cover Java fundamentals from the beginning in a clear and detailed way.

---

## 1. Introduction to Java

Java is a high-level, object-oriented programming language developed by Sun Microsystems, which is now owned by Oracle.

Java is called a high-level language because it is easy for humans to read and understand compared to low-level machine languages.

Java is called object-oriented because most programming in Java is done using classes and objects. Object-oriented programming helps us organize code in a clean and reusable way.

Java is designed to be platform-independent. This means that a Java program can run on different operating systems such as Windows, macOS, and Linux without changing the code, as long as the system has a Java Virtual Machine, also called JVM.

One of the most famous principles of Java is:

> **Write Once, Run Anywhere (WORA)**

This means that we can write Java code once, compile it once, and run it on any device that supports Java.

Java achieves this using bytecode. When we compile a Java program, it is not directly converted into machine code. Instead, it is converted into bytecode. This bytecode is executed by the JVM.

---

## 2. Features of Java

Java provides many important features that make it powerful, secure, and widely used.

### 2.1 Platform Independence

Java is platform-independent because Java programs are compiled into bytecode instead of platform-specific machine code.

The bytecode can run on any operating system that has a JVM.

For example, if we write and compile a Java program on Windows, the generated bytecode can also run on Linux or macOS.

This makes Java very useful for developing applications that need to work on multiple platforms.

---

### 2.2 Object-Oriented

Java is an object-oriented programming language.

This means Java uses concepts such as classes, objects, inheritance, polymorphism, abstraction, and encapsulation.

Object-oriented programming helps developers write code that is reusable, maintainable, and easier to understand.

For example, instead of writing all code in one place, we can divide code into multiple classes based on responsibilities.

---

### 2.3 Simple and Easy to Learn

Java is considered simple compared to languages like C and C++.

Java removes complex concepts such as explicit pointers and manual memory management.

Java also provides automatic garbage collection, which means unused objects are removed from memory automatically.

Because of this, beginners can focus more on programming logic instead of memory handling.

---

### 2.4 Secure

Java provides a secure execution environment.

Java programs run inside the JVM, and the JVM controls how the program accesses system resources.

Java does not support direct memory access through pointers, which reduces many security risks.

This makes Java suitable for developing secure applications.

---

### 2.5 Robust

Java is called robust because it has strong memory management, exception handling, and type checking.

Java checks many errors during compile time and runtime.

Exception handling allows developers to handle unexpected situations without crashing the program immediately.

Garbage collection also helps prevent memory leaks by automatically removing unused objects.

---

### 2.6 Multithreaded

Java supports multithreading.

Multithreading means a program can perform multiple tasks at the same time.

For example, one thread can handle user input while another thread performs background calculations.

This feature is useful for building fast and responsive applications.

---

### 2.7 Portable

Java is portable because compiled bytecode can be moved and executed on any platform that supports JVM.

Java also has standard libraries that behave consistently across platforms.

This makes Java applications easier to transfer between different environments.

---

## 3. Java Architecture

To understand how Java works, we need to understand three important components:

- JDK
- JRE
- JVM

These three components are closely related but have different responsibilities.

---

## 3.1 Java Development Kit

JDK stands for Java Development Kit.

The JDK is used by developers to create Java applications.

It contains everything required to write, compile, and run Java programs.

The JDK includes:

- Java compiler
- Java Runtime Environment
- Java libraries
- Development tools

The Java compiler is called `javac`.

The compiler converts Java source code into bytecode.

Example:

```bash
javac Main.java
